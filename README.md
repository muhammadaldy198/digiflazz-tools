# Digiflazz Tools

Personal Digiflazz seller manager on Cloudflare Workers + D1.

## Fitur
- Koneksi session Digiflazz terenkripsi AES-GCM
- Sinkron kategori dan produk
- Pool seller + scoring
- Ganti seller manual
- Lock produk
- Preferred / blocked seller
- Deteksi perubahan harga dan seller
- Monitor terjadwal setiap 5 menit
- Auto-switch opsional (default OFF, maksimal 20 switch per siklus)
- Proactive cheaper-seller detection
- Riwayat perubahan dan switch
- Cloudflare Access owner-only

Jangan pernah commit cookie, HAR, cURL session, password, atau API credential.
